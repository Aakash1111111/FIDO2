What happens

  1. The site sends a one-time random challenge.
  2. Your browser passes it to the token together with this site's address.
  3. The token waits for you to press its BOOT button, then signs with a key that never leaves the token.
  4. The site checks the signature with the public key it stored when you registered. No password is ever used.
